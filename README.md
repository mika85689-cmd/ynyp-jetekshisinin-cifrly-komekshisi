# Сынып жетекшісінің цифрлық көмекшісі

Әкімші және сынып жетекшілері үшін серверлік веб-қосымша.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/mika85689-cmd/ynyp-jetekshisinin-cifrly-komekshisi)

Орналастыру кезінде Render `render.yaml` файлын оқып, веб-сервис пен PostgreSQL дерекқорын автоматты түрде дайындайды.
